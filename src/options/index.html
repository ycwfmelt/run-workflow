集中管理 TypeSafe System One 核心凭据、S2 工作流调度器及反风控仿真机制
1. TypeSafe Jev (System One 执行层) 核心视觉决策
用于调用 TypeSafe AI 强类型微模型（~100ms 快速决策）。执行侧边栏不会保存或明文展示您的 Key。
Jev 返回概率低于该阈值时将自动重试或等待渲染，默认推荐 0.70 (有效范围 0.10 ~ 1.00)。
2. System Two (S2 动态工作流编排模型) 固定预置
默认连接本地 Ollama 服务（默认 11434 端口）。若本地未启动 Ollama，系统将在侧边栏和执行轨迹中明确显示离线状态及终端启动指引（如 ollama serve）。
3. 人机防风控 (CDP Hardware Emulation) 固定全量启用 ✓
系统已永久锁定开启真实人类行为仿真。通过 Chrome DevTools Protocol 硬件输入层模拟，彻底规避各类企业系统及第三方反自动化风控检测：
🎯 三次贝塞尔平滑鼠标轨迹 (Cubic Bezier)
⚡ Fitts 定律仿人物理加减速模型
🌊 终点高斯微抖动拟合 (Micro-Jitter)
⌨️ 随机泊松分布击键延时 (Gaussian Typing Delay)
🛡️ 真实鼠标按下/释放微停顿 (Natural Click Hold)
4. 动态工作流 Recipe 管理 (Workflow Manager) JS 动态原语
动态工作流将自动化流程固化为纯 JavaScript 异步函数。运行时原生执行，支持条件判断、循环分支，并可通过 URL 规则在目标网页一键秒级调出。
🎯 URL 匹配规则说明与实时测试器 支持 4 种匹配语法
• * 或留空：全局适用（所有网址生效）
• 域名/路径子串：如 crm.example.com 或 github.com/pulls
• 通配符 Glob：如 *.example.com/* 或 https://*
• 正则表达式：如 /^https:\/\/.*\.example\.com/i
